# Модуль Monobank для OkayCMS

Оплата замовлень карткою, Apple Pay і Google Pay через інтернет-еквайринг monobank (plata by mono).

## Що робить

- Покупець натискає «Оплатити» на сторінці замовлення і переходить на сторінку оплати monobank. Там він бачить кошик: назви, кількість, ціни й фото товарів.
- Після оплати monobank надсилає вебхук. Модуль перевіряє підпис і те, що сума й валюта збігаються із замовленням. Після цього він позначає замовлення оплаченим, надсилає листи покупцю й адміну та закриває замовлення (списує залишки).
- Деталі платежу записуються в історію замовлення: InvoiceID, маска картки, RRN, платіжна система. Якщо підключено пРРО, туди ж іде номер фіскального чека й посилання на нього.
- Якщо оплата не пройшла, в історії з'являється причина від monobank, наприклад «На картці недостатньо коштів (код 59)». Повернення коштів теж записується в історію.
- Можна блокувати кошти замість списання (холд).
- Для фіскального чека можна передавати код товару, штрих-код, УКТ ЗЕД і текст до та після назви з властивостей товару.

## Вимоги

- PHP 8.5+
- OkayCMS 4.5.3 (чиста або [форк](https://github.com/devSviat/OkayCMS-Fork))
- Перевірено на PHP 8.5: на чистій OkayCMS 4.5.3 і на форку

## Встановлення

### Варіант 1: архів з GitHub

1. Скачайте архів з [останнього релізу](https://github.com/devSviat/Monobank-OkayCMS/releases/latest).
2. Розпакуйте його в `{OkayCMS_root}/Okay/Modules/`.

### Варіант 2: Git

```bash
cd {OkayCMS_root}/Okay/Modules/Sviat
git clone https://github.com/devSviat/Monobank-OkayCMS.git Monobank
```

Модуль має опинитися тут:

```
{OkayCMS_root}/Okay/Modules/Sviat/Monobank/
```

Далі: адмін-панель → Модулі → `Sviat/Monobank` → «Встановити».

## Налаштування

1. Візьміть токен у кабінеті [web.monobank.ua](https://web.monobank.ua) (розділ еквайрингу). Для перевірки підійде тестовий токен з [api.monobank.ua](https://api.monobank.ua).
2. Адмін-панель → Налаштування → Способи оплати → додайте спосіб оплати з модулем Monobank і вставте токен.

У кабінеті monobank більше нічого вказувати не треба. Адресу для вебхуків модуль передає з кожним рахунком сам.

На сторінці модуля (Модулі → Monobank) є ще три групи параметрів.

### Мова назв товарів

Цією мовою покупець бачить кошик на сторінці оплати, і нею ж назви друкуються у фіскальному чеку. За замовчуванням береться мова, якою оформлено замовлення.

### Холд

Гроші блокуються на картці, а замовлення одразу позначається оплаченим. Списати чи скасувати блокування треба у web.monobank.ua протягом 9 днів, інакше гроші повернуться покупцю. Працює лише з гривнею.

### Фіскальний чек

Ці поля потрібні, лише якщо у web.monobank.ua підключено пРРО або Checkbox. Значення беруться з властивостей товару. Податкова ставка тут означає номер ставки з порталу Checkbox; пРРО monopay ставок поки не застосовує.

## Безпека

- Вебхук приймається лише з дійсним підписом ECDSA від monobank. Відкритий ключ кешується і запитується знову, тільки коли підпис зі збереженим ключем не сходиться.
- Оплата зараховується, лише коли сума й валюта у вебхуку збігаються із замовленням. Повторний вебхук нічого не змінює.
- Посилання на створення рахунку містить секретний код замовлення. Номери замовлень ідуть підряд, тож за ними кожен міг би відкрити чужі замовлення.
